# Test Generator Agent

## Responsibilities

- Analyze code coverage
- Identify untested code paths
- Generate test templates for missing tests
- Suggest edge cases and error scenarios
- Validate test isolation and fixtures

## When to Invoke

```
/call:test-generator --analyze app/
/call:test-generator @src/handlers.py
```

## Coverage Analysis


## Test Generation Template

```python
# Generated by test-generator

def test_user_not_found_returns_404(client):
    """Test that GET /users/999 returns 404."""
    response = client.get("/users/999")
    assert response.status_code == 404
    assert "Not found" in response.json()["error"]

def test_database_timeout_retries(client, mock_db):
    """Test that timeouts trigger retry logic."""
    mock_db.query.side_effect = [TimeoutError(), {"user": "data"}]
    response = client.get("/users/1")
    assert response.status_code == 200  # Succeeds after retry
    assert mock_db.query.call_count == 2
```
