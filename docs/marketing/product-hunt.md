## Description
```
One-Shot Prompting is a Claude Code plugin that turns a feature description 
into production-ready code in 2-3 minutes.

Type: /one-shot "Add shopping cart with line items" @./my-project

You get back:
✅ Models, schemas, services, routers
✅ 12 passing tests
✅ Reversible database migration
✅ Wired into your main.py

Works with FastAPI, Django, Spring Boot, Go, NestJS, Node.js.

It reads YOUR codebase first — so the code it generates fits your patterns,
not generic boilerplate. Free to use. MIT license.
```
