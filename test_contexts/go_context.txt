### Raw SQL Queries
```go
package db

import "database/sql"

func GetUser(id string) (*User, error) {
    var user User
    err := db.QueryRow(
        "SELECT id, name, email FROM users WHERE id = $1",
        id,
    ).Scan(&user.ID, &user.Name, &user.Email)
    if err != nil {
        return nil, err
    }
    return &user, nil
}
```
**Pattern:** Raw SQL with database/sql package (no ORM).
