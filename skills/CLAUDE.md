## How to Use This Directory

**For development:**

- Test a skill: see `docs/testing.md` for CLI invocation

**For reference:**
- All SKILL.md files are < 2000 lines (readable in one sitting)
- Each skill has a `scripts/` subdirectory with Python helpers
- Phase 0-3 skills are production-ready; Phase 4-5 have stub scripts only

## The Main Skill: one-shot-generator

**Status:** ✅ Production ready (Phases 0-3)

1,677 lines. Orchestrates: planning → multi-file formatting → framework-specific code generation → testing.

Scripts: `one-shot-generator/scripts/`
- analyze_codebase.py (framework detection)
- phase2_rest_api/ (44 generators)
- phase3_batch_jobs/ (13 generators)
- phase4_*, phase5_* (stubs only — see `docs/phase-status.md`)

**Invocation:**
```bash
/one-shot-prompting:one-shot-generator "add user auth" @/path/to/project
```

## Supporting Skills

All thin wrapper skills. Each has 78-99 lines + one helper script.

### write-plan

Generates step-by-step plan before code generation.

**When to use:** Planning phase, before invoking one-shot-generator

**Invocation:**
```bash
/one-shot-prompting:write-plan "add JWT auth with refresh tokens" @/project
```

### execute-plan

Executes a plan generated by write-plan.

**When to use:** After planning, to implement the plan

**Invocation:**
```bash
/one-shot-prompting:execute-plan "run step 1-3 of the plan" @/project
```

### tdd-cycle

Enforces test-driven development: generate test → fail → implement → verify pass.

**When to use:** When rigor is critical, or when teaching TDD

**Invocation:**
```bash
/one-shot-prompting:tdd-cycle "add payment processing" @/project
```

### systematic-debug

Analyzes error logs and pinpoints root cause.

**When to use:** Generated code has errors; need debugging

**Invocation:**
```bash
/one-shot-prompting:systematic-debug /path/to/error-log.txt @/project
```

### verify-before-complete

Gate: confirm generated output is correct before returning.

**When to use:** High-stakes generation; need verification before applying

**Invocation:**
```bash
/one-shot-prompting:verify-before-complete @/project
```

## Modification Rules

1. **SKILL.md changes:**
   - Keep < 1000 lines (split if needed)
   - Must have YAML frontmatter: `name`, `description`, `trigger`
   - Must have ! injection block calling a script
   - Update CHANGELOG.md + plugin.json version

2. **Script changes:**
   - Keep: Python stdlib only (no pip dependencies)
   - Keep: zero external APIs (local processing only)
   - Add: test file if new script created
   - Run: smoke-test.sh + RUN_INTEGRATION_TESTS.py before commit

3. **Phase 4-5 scripts:**
   - DO NOT edit/invoke without opening a .beads bead first
   - These are stubs, not working code
   - See `docs/phase-status.md` for reality
