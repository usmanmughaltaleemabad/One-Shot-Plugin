## Critical Rules

1. **Go 1.21+** with Chi HTTP router
2. **75%+ test coverage** via table-driven tests
3. **Interface-based design** for all services
4. **Explicit error handling** with error wrapping
5. **Redis caching** for product catalog
6. **Context propagation** through request lifecycle
