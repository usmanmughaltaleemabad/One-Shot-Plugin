## What Each Project Demonstrates

### Harness Integration
Each project includes:
- `.claude/CLAUDE.md` (framework-specific router)
- `.claude/standards/` (code style, testing, security)
- `.claude/agents/` (code-reviewer, test-gen, performance)
- `.claude/hooks/` (pre/post execution validation)
- `.claude/beads/` (tracks what was generated)

### One-Shot Integration
Each project was generated using One-Shot Plugin + Harness:
1. One-shot reads `.claude/CLAUDE.md`
2. Detects framework
3. Loads standards
4. Generates code respecting standards
5. Runs validation agents
6. Tracks decision in beads

### Production-Ready Code
- ✅ Working models + APIs
- ✅ 75-85%+ test coverage
- ✅ Security validations
- ✅ Performance optimizations
- ✅ Error handling
- ✅ Database migrations (where applicable)

## How to Use These Examples

### 1. Explore a Project

```bash
cd examples/django-order-service-harness/
cat .claude/CLAUDE.md                    # See harness config
cat .claude/standards/code-style-django.md  # See code style rules
python manage.py runserver               # Run it
pytest --cov=app                         # See test coverage
```

### 2. Understand One-Shot Generation

Each project README explains:
- What one-shot read from harness
- How it detected the framework
- What standards it applied
- What agents validated the code
- What was tracked in beads

### 3. Generate Similar Features

Use the pattern to generate more:

```bash
/one-shot-prompting:one-shot-generator \
  "Add user authentication with OAuth2" \
  @examples/fastapi-payment-processor-harness

# One-shot will:
# 1. Read .claude/CLAUDE.md
# 2. Detect FastAPI 0.104
# 3. Load security standards
# 4. Generate OAuth2 implementation
# 5. Run agents (security-scanner, test-gen)
# 6. Return production-ready code
```

## Quick Reference

### Install & Run Django Example

```bash
cd examples/django-order-service-harness
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
pytest --cov=app
python manage.py runserver
```

### Install & Run FastAPI Example

```bash
cd examples/fastapi-payment-processor-harness
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pytest --cov=app
uvicorn main:app --reload
```

### Install & Run Spring Example

```bash
cd examples/spring-user-service-harness
mvn clean install
mvn test
mvn spring-boot:run
```

### Install & Run Go Example

```bash
cd examples/go-product-service-harness
go mod download
go test ./...
go run main.go
```

### Install & Run Node Example

```bash
cd examples/nodejs-realtime-api-harness
npm install
npm test
npm run dev
```
