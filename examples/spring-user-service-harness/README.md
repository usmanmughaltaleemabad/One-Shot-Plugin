# Spring Boot User Management with Harness

**Complete working example** showing ONE SHOT PLUGIN + Harness integration.

## What This Project Shows

- ✅ Harness governance (`.claude/` config)
- ✅ One-shot code generation (harness-aware)
- ✅ Standards enforcement (JPA, MockMvc, security)
- ✅ Agent validation (code-reviewer, test-gen)
- ✅ Production-ready code (user CRUD, roles, permissions, audit logging)

## Quick Start

```bash
# 1. Build and setup
cd One-Shot-Plugin/examples/spring-user-service-harness
mvn clean install

# 2. Run tests
mvn test

# 3. Start dev server
mvn spring-boot:run

# 4. View harness
cat .claude/CLAUDE.md
```

## How ONE-SHOT Generated This

### 1. Read Harness

One-shot reads `.claude/CLAUDE.md`:
```markdown
# User Management Service

## Critical Rules
1. Spring Boot 3.2+ with JPA
2. 80%+ test coverage required
3. Role-based access control
4. Audit logging on all mutations
5. Spring Security with JWT auth
```

### 2. Detect Framework

One-shot detects: **Spring Boot 3.2 + Spring Data JPA + Spring Security**

### 3. Load Standards

One-shot loads `.claude/standards/`:
- Code style: Java conventions, dependency injection
- Testing: MockMvc, JUnit 5, @DataJpaTest
- Security: Input validation, permission checks

### 4. Generate Code

One-shot generates:
- Entities: User, Role, AuditLog (JPA)
- Repositories: Spring Data JPA
- Services: UserService with business logic
- Controllers: REST API endpoints
- DTOs: Request/response models
- Tests: MockMvc integration tests (80%+ coverage)

### 5. Run Agents

One-shot runs:
- **code-reviewer**: ✅ Approved
- **test-generator**: ✅ 80% coverage met

### 6. Track Decision

One-shot records in `.claude/beads/status.jsonl`

## API Endpoints

```bash
# Users
GET /api/users                    # List (paginated)
POST /api/users                   # Create
GET /api/users/{id}               # Get
PUT /api/users/{id}               # Update
DELETE /api/users/{id}            # Delete
POST /api/users/{id}/roles        # Assign role

# Roles
GET /api/roles
POST /api/roles
GET /api/roles/{id}
```
