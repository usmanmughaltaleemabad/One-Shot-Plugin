## Critical Rules

1. **Spring Boot 3.2+** with Spring Data JPA
2. **80%+ test coverage** via MockMvc
3. **Role-based access control** enforced on all endpoints
4. **Audit logging** on all data mutations
5. **JPA relationships** use lazy loading with @Fetch
6. **Transaction boundaries** explicit (@Transactional)
