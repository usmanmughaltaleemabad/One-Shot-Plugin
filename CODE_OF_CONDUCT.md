# Code of Conduct

We adopt the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as our community standards.

## Summary (full text below)

- **Be respectful.** Disagreement is fine; personal attacks are not.
- **Assume good faith.** Most "bad" PRs are good-faith mistakes.
- **Stay technical.** Off-topic political / personal arguments belong
  elsewhere.
- **Concrete > generic.** "Your code is bad" is not feedback; "your
  function leaks file handles because X" is.

## Enforcement

Issues that violate this code may be:
1. Locked for cooldown
2. Deleted if abusive
3. The author blocked from the repository for repeated violations

Report violations to musman.mughal@taleemabad.com (subject:
"[code-of-conduct] ...").
